# 筋トレ リサーチノート

調査日: 2026-10-14 / 出典: Consensus(各検索で上位3件まで)

## 1. 根本原則
- 漸進性過負荷(重量・回数・セット数を少しずつ増やす)が土台。
- ACSM 2026ポジションスタンド(137レビュー、3万人超)は、健康な成人に漸進的レジスタンストレーニングを推奨。

## 2. トレーニング変数(優先順)

| 変数 | 知見 | 実践目安 |
|---|---|---|
| ボリューム | 週セット数が多いほど筋肥大。1セット追加で約0.37%増。収穫逓減あり、明確な頭打ちは未確認。ACSMは週10セット以上を推奨 | 1部位あたり週10〜20セット(外挿を含む推奨) |
| 限界への近さ(RIR) | 筋肥大は限界に近いほど有利。筋力はRIRの影響が小さい。ACSMは完全限界の一貫した優位を認めず | RIR 0〜3 |
| 負荷 | 限界まで行えば筋肥大は負荷に依存しない。筋力は高負荷(8RM以下)が有利 | 5〜30回、主要種目は5〜10回中心 |
| 頻度 | 筋肥大への独立効果は小さい。筋力は頻度が高いほど伸びる(逓減あり) | 各部位 週2回以上 |
| 差が出にくいもの | 器具、種目の複雑さ、テンポ、血流制限、周期化 | 後回しでよい |

## 3. 栄養
- タンパク質: 約1.6g/kg/日が目安(1.62g/kg/day超で除脂肪量の追加増加なし)。
- 65歳以上: 1.2〜1.6g/kg/day。
- 減量中: 1.3g/kg/day超で筋量維持、1.0g/kg/day未満は低下リスク。
- カロリー(一般知見): 増量は小さな余剰、減量は高タンパク+筋トレ継続。

## 4. 回復(一般知見・今回は検索していない)
- 睡眠7時間以上。同一部位の間隔は48時間前後。疲労が溜まったら量を減らす。

## 5. 考え方
1. 継続が最大の変数。
2. 優先順位: 総量 → 漸進性 → 限界の近さ → タンパク質 → 睡眠。
3. 重量・回数・セット数を記録して判断。
4. 目的で優先を変える(肥大=量と限界、筋力=高負荷と頻度、パワー=中負荷で速く)。
5. 個人差を前提にする(初心者は伸びやすい)。
6. フォームと安全を優先。痛みが出たら中止。

## 6. 注意点
- 対象は主に若年・健康な成人男性。女性・高齢者・持病のある方にはそのまま当てはまらない場合がある。
- 各検索3件までの抜粋で、網羅的レビューではない。
- RIRの分析は探索的で、推定に不確実性がある。
