# 筋トレ記録アプリ

トレーニング種目・食事・体重を日付ごとに記録するシンプルなWebアプリです。ビルド不要、`index.html` をブラウザで開くだけで動きます。データはブラウザの localStorage に保存されます。

## 機能
- **トレーニング記録**: 部位・種目・重量・回数・セット数、1日の総ボリューム表示
- **食事記録**: 食事区分、kcal、PFC。よく食べる食品のプリセット入力
- **写真から自動計算(AI)**: 食事を撮影するとClaude Visionが料理を分解し、基準物(皿・箸・缶など)から量(g)を推定、kcal・PFCを算出。グラム修正で再計算。履歴・設定タブでAPIキーを設定
- **トレーニングスタイル設定**: 分割法(全身/2/3/4/5分割)・週の回数・経験・目的・器具・時間・補足を「履歴・設定」で保存。おすすめの種目・重量に反映
- **おすすめ**: 分割法の「今日のグループ」に沿って次の種目と、漸進性過負荷による重量・回数を提案。「AIで今日のメニューを作る」でAIがスタイルと履歴から全体メニューを作成(アーティファクトではClaude利用枠、通常ブラウザではAPIキーを使用)
- **体重記録**: 体重・体脂肪率、推移グラフ
- **履歴・統計**: 日別サマリー、1日の目標(kcal/タンパク質)達成度
- **バックアップ**: JSONの書き出し/読み込み

## アプリとして使う(PWA)
HTTPS(または localhost)で配信すると、スマホの「ホーム画面に追加」でアプリとして起動でき、オフラインでも記録できます。
- Android/Chrome: メニューの「アプリをインストール」/ 設定タブの「ホーム画面に追加」ボタン
- iPhone/Safari: 共有ボタン →「ホーム画面に追加」
- ファイルを更新したら `sw.js` の `CACHE` のバージョンを上げる
- アイコンの再生成: `node tools/make-icons.js`

## 構成
```
index.html      画面
css/style.css   スタイル
js/data.js      種目・食品のプリセット
js/storage.js   localStorage 入出力
js/foodai.js    食事写真の解析(Claude API)
js/coachai.js   スタイル+履歴からの今日のメニュー提案(AI)
js/app.js       画面ロジック
js/pwa.js       サービスワーカー登録・インストール案内
sw.js           オフライン用キャッシュ
manifest.webmanifest  アプリ名・アイコン・表示設定
icons/          アプリアイコン(tools/make-icons.js で生成)
```
